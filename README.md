# INFOB Digital Solutions Portfolio

A modern, high-performance portfolio website built for a digital agency using React, Tailwind CSS, and Framer Motion.

## Features
- **3D Animated Hero**: Custom Framer Motion powered 3D geometric parallax hero section.
- **Glassmorphism UI**: High-end sleek dark/light mode adaptable UI.
- **Project Showcase**: Fully functional Bento Grid layout for case studies and live demos.
- **Resend API Integration**: Live contact form powered by Vercel serverless functions and Resend.

## Tech Stack
- React 18
- Vite
- Tailwind CSS
- Framer Motion

## Getting Started

1. Clone the repository
2. Run \`npm install\`
3. Create a \`.env\` file with your \`RESEND_API_KEY\`
4. Run \`npm run dev\` to start the development server.
